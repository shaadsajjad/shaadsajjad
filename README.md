### Shiftick: Attendance & Work-Time Tracker
[Google Play](https://play.google.com/store/apps/details?id=com.invalidco.officehour.office_hour&hl=en) · Flutter · PocketBase · Solo build

I designed and built the whole app, from the architecture, UI and backend structure through to the Play Store release.

- **Shift-setup onboarding:** a multi-step flow that turns an owner's working hours into rules
- **Roster & scheduling:** per-employee weekly schedules, day-off handling, automatic shift-time resolution
- **Team management:** role-based access and shift assignment

**Architecture:** feature-first clean architecture · BLoC/Cubit · PocketBase backend with server-side hooks · go_router · EasyLocalization for multiple languages
